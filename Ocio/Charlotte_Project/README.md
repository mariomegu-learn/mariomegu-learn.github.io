# Avión eléctrico de madera — Presentación web

Presentación interactiva de seis diapositivas creada con HTML, Tailwind CSS, CSS personalizado, JavaScript y Font Awesome.

## Abrir

Abre `index.html` en un navegador moderno. Para una vista más confiable, sirve la carpeta con un servidor local.

## Controles

- Flechas izquierda/derecha, Page Up/Page Down o botones inferiores.
- Deslizamiento horizontal en pantallas táctiles.
- Botón de pantalla completa.
- Simulación encendido/apagado en la diapositiva del circuito.
- El nombre y el curso de la portada se pueden editar directamente.
